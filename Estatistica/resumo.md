# Resumo - Estatística Aula 1

## Conceito Principal
Estatística é a ciência que coleta, organiza, analisa e interpreta dados para auxiliar na tomada de decisões.

## Áreas da Estatística
- **Descritiva**: Organiza e sintetiza dados já ocorridos (sem incerteza)
- **Probabilidade**: Lida com eventos aleatórios e incerteza
- **Indutiva (Inferencial)**: Usa amostras para estimar características da população (com margem de erro)

## Conceitos Fundamentais

### População e Amostra
- **População**: Coleção completa de todos os elementos de interesse
- **Amostra**: Subconjunto da população (mais rápido, barato e eficiente)
- Boa amostra = representa todas as características da população na proporção correta

### Dados Brutos e Rol
- **Dados Brutos**: Valores não organizados
- **Rol**: Dados organizados (crescente/decrescente)

### Tipos de Variáveis

```
                    VARIÁVEIS
                        │
        ┌───────────────┴────────────────┐
        │                                │
   QUANTITATIVAS                    QUALITATIVAS
   (mensuráveis)                    (categóricas)
        │                                │
    ┌───┴────┐                    ┌──────┴──────┐
 Discretas Contínuas            Nominais    Ordinais
```

**Quantitativas** (mensuráveis):
- **Discretas**: Valores contáveis/inteiros (ex: nº de filhos, nº de alunos)
- **Contínuas**: Valores fracionários possíveis (ex: altura, peso, temperatura)

**Qualitativas** (categóricas):
- **Nominais**: Sem hierarquia (ex: sexo, cor dos olhos, nacionalidade)
- **Ordinais**: Com hierarquia (ex: escolaridade, faixa etária, classe social)

## Distribuição de Frequências

### Tipos de Frequência
- **Simples Absoluta (fᵢ)**: Contagem de ocorrências
- **Simples Relativa (fᵣᵢ)**: fᵢ / N (unitária ou percentual)
- **Acumulada Absoluta (Fᵢ)**: Soma acumulada das frequências

### Classes
- **Discreta**: Um único valor por classe
- **Intervalar**: Intervalo de valores (para variáveis contínuas)

### Representação Gráfica
- **Histograma**: Gráfico de colunas justapostas para classes intervalares
- **Polígono de Frequências**: Linha conectando pontos médios das classes

## Fórmulas Importantes
- N = Σfᵢ (total de elementos)
- fᵣᵢ = fᵢ / N (frequência relativa)
- fᵣᵢ% = (fᵢ / N) × 100
- Fᵢ = Fᵢ₋₁ + fᵢ (frequência acumulada)

## Exemplo Prático

**Situação:** Notas de 9 alunos em uma prova

**Dados brutos:** 9, 4, 6, 7, 8.5, 3, 8, 10, 10

**Rol (ordem crescente):** 3, 4, 6, 7, 8, 8.5, 9, 10, 10

**Tabela de Frequências:**

| Nota | fᵢ (freq. absoluta) | fᵣᵢ% (freq. relativa %) |
|------|---------------------|-------------------------|
| 3    | 1                   | 11,1%                   |
| 4    | 1                   | 11,1%                   |
| 10   | 2                   | 22,2%                   |
| ...  | ...                 | ...                     |
| Total| N = 9               | 100%                    |

## Referência Rápida

| Conceito | Quando Usar | Característica |
|----------|-------------|----------------|
| Dados Brutos | Coleta inicial | Não organizados |
| Rol | Organização básica | Mesma quantidade, ordenados |
| Frequência Absoluta | Contagem simples | Número de ocorrências |
| Frequência Relativa | Comparação percentual | Proporção do total |
| Frequência Acumulada | Ver totais progressivos | Soma até determinado ponto |
| Histograma | Visualizar distribuição | Variáveis contínuas |

## Pontos-Chave para Lembrar

✓ **Boa amostra ≠ amostra grande** — O importante é representar todas as características da população

✓ **Rol mantém o mesmo número de elementos** — Apenas organiza, não reduz dados

✓ **Variáveis discretas = contáveis** (inteiros) | **Contínuas = mensuráveis** (fracionários)

✓ **Σfᵢ sempre = N** — A soma de todas as frequências absolutas é o total de elementos

✓ **Estatística Descritiva ≠ Inferencial** — Descritiva descreve o passado (sem incerteza), Inferencial estima o futuro (com margem de erro)

## Aplicações Práticas
A estatística descritiva permite transformar grandes volumes de dados brutos em informações organizadas e interpretáveis através de tabelas e gráficos, facilitando a análise e tomada de decisões em áreas como:
- Pesquisas de mercado
- Controle de qualidade
- Análise de desempenho acadêmico
- Estudos populacionais
