Lógica de Programação

Entenda a diferença entre algoritmo e programa

Algoritmo

Sequência de instruções para realizar uma tarefa. Pode ser executado por humanos (como uma receita de bolo).

Programa

Algoritmo implementado em linguagem de programação. Executado por processadores digitais.

Python

Linguagem de alto nível criada por Guido van Rossum em 1991. Usa interpretador (executa linha por linha).

Operadores

Operadores Aritméticos

Operador Operação Exemplo
+ Adição 3 + 7 = 10
- Subtração 3 - 7 = -4
* Multiplicação 3 * 2 = 6
/ Divisão 5 / 2 = 2.5
// Divisão inteira 15 // 2 = 7
% Resto da divisão 15 % 2 = 1
** Potenciação 2 ** 3 = 8

Operadores Relacionais

Operador Operação Retorna
< Menor que True ou False
> Maior que True ou False
== Igual a True ou False
!= Diferente de True ou False

Tipos de Dados Básicos

int

Número inteiro

x = 10
y = -5

float

Número real (ponto flutuante)

pi = 3.14
temp = 36.5

str

String/texto

nome = 'Maria'
msg = "Olá"

bool

Booleano (verdadeiro/falso)

ativo = True
vazio = False

Funções Essenciais

input()

Coleta texto do teclado (retorna sempre str)

nome = input("Digite seu nome: ")

print()

Exibe mensagem na tela

print("Olá, mundo!")
print(f"Nome: {nome}")

int() / float()

Converte para inteiro ou real

num = int(input("Número: "))
valor = float("3.14")

type()

Verifica o tipo da variável

x = 10
type(x) # <class 'int'>

Exemplo Completo

Programa que calcula o dobro de um número

# Programa que calcula o dobro de um número num = int(input("Digite um nº inteiro: ")) print(f"Dobro de {num} é {num * 2}") # input() sempre retorna string # Converter com int() ou float() se necessário

Conceitos-Chave

✓ Python é interpretado — Não compilado. Executa linha por linha.
✓ input() sempre retorna string — Converter com int() ou float() se necessário.
✓ F-strings facilitam interpolação — Use f"..." para inserir variáveis em strings.
✓ Variáveis podem mudar de tipo — Python é dinamicamente tipado.
✓ Precedência: () → ** → * / // % → + - — Use parênteses para controlar ordem.
