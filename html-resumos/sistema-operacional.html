Válvulas — ~20.000 válvulas, sem SO. Programador operava diretamente a máquina.

TIPOS DE SO

MONOPROGRAMÁVEIS

Um programa por vez. Recursos exclusivos, baixo aproveitamento da CPU.

MULTIPROGRAMÁVEIS

Vários programas compartilham recursos. Alto aproveitamento da CPU.

BATCH

Sem interação do usuário. Cálculos, compilações, backups.

TIME-SHARING

Fatias de tempo divididas entre processos. Cada usuário tem terminal.

TEMPO REAL

Prazos rígidos (deadlines). Controle de voo, UTI, freios ABS.

MÚLTIPLOS PROCESSADORES

Dois ou mais processadores trabalhando em conjunto.

MULTIPROGRAMAÇÃO

Memória dividida em partições, CPU alterna entre tarefas

┌─────────────────────────────────────────────────────┐ │ MEMÓRIA PRINCIPAL │ ├─────────────────────────────────────────────────────┤ │ Partição 1 │ Tarefa A │ (aguardando E/S...) │ ├─────────────────────────────────────────────────────┤ │ Partição 2 │ Tarefa B │ (usando CPU agora!) ◄── │ ├─────────────────────────────────────────────────────┤ │ Partição 3 │ Tarefa C │ (aguardando CPU...) │ ├─────────────────────────────────────────────────────┤ │ Partição 4 │ Tarefa D │ (aguardando E/S...) │ └─────────────────────────────────────────────────────┘ │ ▼ CPU ocupa quase 100% do tempo! Enquanto uma tarefa espera E/S, outra usa a CPU.

FORTEMENTE ACOPLADOS

  • ✓ Memória física compartilhada
  • ✓ Um único SO gerencia tudo
  • ✓ Simétricos e Assimétricos
  • ✓ Ex: Unix, Windows

FRACAMENTE ACOPLADOS

  • ✓ Sistemas independentes conectados
  • ✓ Cada sistema tem seu SO
  • ✓ SO de Rede ou Distribuídos
  • ✓ Ex: Clusters, Cloud
