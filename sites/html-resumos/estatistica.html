Estatística Descritiva

Aprenda os conceitos fundamentais de estatística para coletar, organizar, analisar e interpretar dados na tomada de decisões.

Começar a estudar

Conceito Principal

Estatística é a ciência que coleta, organiza, analisa e interpreta dados para auxiliar na tomada de decisões.

Descritiva

Organiza e sintetiza dados já ocorridos sem incerteza. Trabalha com o passado.

Probabilidade

Lida com eventos aleatórios e incerteza. Campo da chance de algo acontecer.

Indutiva (Inferencial)

Usa amostras para estimar características da população com margem de erro.

Tipos de Variáveis

Entenda a classificação das variáveis estatísticas

VARIÁVEIS │ ┌───────────────┴────────────────┐ │ │ QUANTITATIVAS QUALITATIVAS (mensuráveis) (categóricas) │ │ ┌───┴────┐ ┌──────┴──────┐ Discretas Contínuas Nominais Ordinais

Quantitativas

  • ✓ Discretas: Valores contáveis/inteiros (ex: nº de filhos, nº de alunos)
  • ✓ Contínuas: Valores fracionários possíveis (ex: altura, peso, temperatura)

Qualitativas

  • ✓ Nominais: Sem hierarquia (ex: sexo, cor dos olhos, nacionalidade)
  • ✓ Ordinais: Com hierarquia (ex: escolaridade, faixa etária, classe social)

Distribuição de Frequências

Tipo Descrição Notação
Simples Absoluta Contagem de ocorrências fᵢ
Simples Relativa fᵢ / N (unitária ou percentual) fᵣᵢ ou fᵣᵢ%
Acumulada Absoluta Soma acumulada das frequências Fᵢ

Fórmulas Importantes

Total de Elementos

N = Σfᵢ

Frequência Relativa

fᵣᵢ = fᵢ / N

Frequência Relativa %

fᵣᵢ% = (fᵢ / N) × 100

Frequência Acumulada

Fᵢ = Fᵢ₋₁ + fᵢ

Pontos-Chave para Lembrar

✓ Boa amostra ≠ amostra grande — O importante é representar todas as características da população
✓ Rol mantém o mesmo número de elementos — Apenas organiza, não reduz dados
✓ Variáveis discretas = contáveis (inteiros) | Contínuas = mensuráveis (fracionários)
✓ Σfᵢ sempre = N — A soma de todas as frequências absolutas é o total de elementos
✓ Estatística Descritiva ≠ Inferencial — Descritiva descreve o passado (sem incerteza), Inferencial estima o futuro (com margem de erro)
