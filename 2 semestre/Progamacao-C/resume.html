Comandos de Repetição & Vetores em Linguagem C

De while e for até vetores indexados: a base de quase toda pegadinha de prova envolvendo lógica em C.

Controle de laço Índice / vetor Saída / resultado

§while e break

O while executa um bloco enquanto a condição for verdadeira, testando-a antes de cada repetição. Combinado com while (true), cria-se um laço infinito que só termina quando um break interno é executado — útil quando a condição de parada só é conhecida durante a execução, como um valor digitado pelo usuário.

questao_38.c 
int qtp=0, qti=0, nro;
while (true){
    scanf("%d", &nro);
    if(nro < 0)
        break;
    if ((nro % 2)==0)
        qtp++;
    else
        qti++;
}
entrada 2, 0, 7, 8, 9, 1, -2 → qtp=3, qti=3 (o -2 causa o break e não é contado)

Ponto-chave: o número que provoca o break normalmente não é processado pelas instruções seguintes dentro do laço — ele só serve para encerrar a repetição.

§O laço for

Estrutura compacta para repetições com número definido de execuções. Reúne em uma linha três partes independentes:

i = 0 ; i < n ; i++
inicialização — roda 1 vez, antes do laço condição — testada antes de cada repetição incremento — roda ao fim de cada repetição

Pegadinha clássica: i < n executa n vezes (de 0 a n-1); já i <= n executa n+1 vezes. Trocar um pelo outro muda toda a resposta.

§Executando na mão — soma dos pares

Uma forma segura de não errar em prova é simular o laço linha a linha. Para o trecho abaixo:

questao_45.c 
int v[5] = {2, 4, 6, 8, 10};
int i, sum = 0;
for (i = 0; i < 3; i++) {
    sum += v[i];
}
i condição i<3 v[i] sum
0 verdadeira 2 2
1 verdadeira 4 6
2 verdadeira 6 12
3 falsa — sai do laço — 12

Resultado: Sum = 12. Os elementos v[3]=8 e v[4]=10 nunca são visitados, porque a condição corta o laço em i=3.

§O que é um vetor

Uma variável dimensionada (ou vetor) é uma estrutura que armazena vários conteúdos do mesmo tipo em posições de memória contíguas, acessados por um índice. Diferente de uma variável comum — que guarda um único valor por vez — um vetor guarda vários valores simultaneamente.

Toda variável dimensionada tem quatro propriedades: nome, tipo, conteúdo e quantidade de conteúdo.

§Declaração e inicialização

Forma Efeito
int v[5] = {10,20,30,40,50}; Todos os 5 elementos definidos explicitamente
int v[5] = {20,10}; Elementos não citados (v[2], v[3], v[4]) viram 0 automaticamente
int v[100] = {0}; Forma comum de zerar um vetor inteiro
int v[] = {5,10,15,20}; Tamanho inferido automaticamente pelo compilador — nesse caso, 4
int v[5]; Sem inicialização — conteúdo é lixo de memória

§Índices e limites

Em C, os índices sempre começam em 0. Para um vetor de tamanho N, os índices válidos vão de 0 até N-1 — não existe ajuste automático para índices fora desse intervalo.

[0]-100
[1]100
[2]20
[3]-50
[4]0
[5]?

int numbers[5] — índices válidos de 0 a 4. numbers[5] está fora do vetor: comportamento indefinido, não erro de compilação.

§Vetores com laços

Vetores quase sempre são manipulados junto de laços — para ler, processar ou exibir todos os elementos. Dois padrões aparecem o tempo todo:

leitura.c
for (i = 0; i < tamanho; i++) {
    scanf("%d", &v[i]);
}
soma_pares.c
for (i = 0; i < tamanho; i++) {
    if ((v[i] % 2) == 0) {
        soma += v[i];
    }
}
Como v[i]=i neste caso, pode-se trocar por: for (i=0; i<10; i+=2) soma += v[i];

§Validando acesso a vetores (OK / NOK)

Dado int a, d, num[100]; float b; char c[100]; — quais operações são válidas?

Operação Status Motivo
num[0] = a - 200; OK Atribuição válida entre inteiros
c[5] = 5; NOK Tipos incompatíveis (char recebendo int)
num = b[2]; NOK num é vetor — não recebe atribuição direta; b não é vetor
a = num[d]; OK Válido se d estiver entre 0 e 99
b = num[10]+num[20]+30; OK Operação aritmética válida
num[30] = num[80]+b; NOK Mistura de tipos sem conversão explícita

§Erros conceituais mais cobrados

Índice começando em 1

Índices de vetor sempre começam em 0. Para int vet[n];, o último elemento válido é vet[n-1], nunca vet[n].

Acesso fora do intervalo "seguro"

C não ajusta automaticamente um índice inválido. O resultado é comportamento indefinido, não um erro de compilação.

Vetor sem inicialização

Um vetor declarado sem valores contém lixo de memória — ler esse conteúdo produz resultados imprevisíveis.

§Exercícios propostos

Exercício — soma dos n primeiros

Faça um programa em C que leia n, calcule e imprima a soma dos n primeiros inteiros, começando em 0 e terminando em n.

int i, n, soma=0;
scanf("%d", &n);
for(i=0;i<=n;i++){
    soma += i;
}
Exercício — pares e ímpares

Leia inteiros positivos até que o usuário digite um número negativo. Ao final, imprima quantos números pares e quantos ímpares foram digitados.

Entrada: 9, 8, 6, 3, 4, -1 → Qtde par = 3, Qtde impar = 2

Exercício — vetor invertido

Leia 3 valores em um vetor e imprima-os em ordem inversa, usando um laço decrescente.

Entrada: 10, -20, 30 → Vector values: 30 -20 10

§Glossário rápido

while
Repete enquanto a condição for verdadeira; teste no início do laço.
for
Repete com contador definido: inicialização + condição + incremento.
break
Interrompe o laço mais interno imediatamente.
Vetor (array)
Variável que armazena múltiplos valores do mesmo tipo, em memória contígua.
Índice
Posição de um elemento no vetor, sempre começando em 0.
Lixo de memória
Conteúdo indeterminado de um vetor não inicializado.
int v[]
Sintaxe onde o compilador infere o tamanho pela quantidade de elementos.
Comportamento indefinido
Resultado de acessar um índice fora do intervalo válido do vetor.
